## titolo
Execution paths

## tema
Cybersecurity

## formula
G = (V, E)
Aᵢⱼ = 1 if there is an edge i → j, otherwise 0

## spiegazione
A program can be described through the relationships between operations, functions or states. The branches and convergences of this network evoke the problem of reconstructing behaviour from execution traces.

## limiti
The graph was constructed to illustrate branching and directed connections; it does not come from malware. Arrows indicate edge direction. Matrix A describes connectivity only and assigns no transition probabilities.

## osservazione
Follow the arrows from a node and observe where the path branches or converges, rotating the network to distinguish crossings in projection from connections actually present between operations, functions or states.

## lettura
Graph G contains vertices V and edges E; an adjacency-matrix entry is one when an edge connects vertex i to vertex j, and zero otherwise.
