# Foto originale, senza modifiche

La homepage deve utilizzare **esclusivamente** il file fotografico originale fornito dall’autore.

**Non** generare, modificare, ricreare, ritagliare, ricolorare, ritoccare o applicare filtri a questa fotografia.

Incollare la fotografia originale come file esattamente in `public/media/images/homepage-portrait.jpg`. Questa consegna non include i byte dell’allegato originale, che non risultano accessibili nel container di lavoro. Per evitare errori la build è bloccata finché quel file manca.

La CSS visualizza l’immagine senza filtri, conservando le proporzioni e il contenuto integrale. Il sito non deve mostrare fotografie sintetiche o generate.
